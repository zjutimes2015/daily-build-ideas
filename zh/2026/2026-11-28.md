# 每日 Build Idea 简报 · 2026-11-28

**一句话摘要：** GitHub 当日涨星第一和第五都是"同时跑一堆编程智能体"的控制台，Product Hunt 周榜第一也是同一件事——做一个只管额度、待批准和结果对比的舰队仪表盘，别再做又一个智能体，抢"管智能体"这个入口。

## 今日 Build Idea：FleetWatch——"你跑了十个智能体，谁在烧额度、谁在等你点头"

**产品：** 编程智能体舰队的额度与待办控制台。它不写代码、不抢 Orca / t3code 的编辑器位置，只做三件事：把你所有机器上正在跑的 Claude Code / Codex / Cursor 会话收进一个收件箱（谁在等批准、谁跑完了、谁失败了）；给每个会话挂上额度表（已用多少、还剩多少、何时重置，撞墙前预警）；同一任务派给多个智能体时，把它们的 diff 并排对比、点选胜者合并。手机上也能批准和打回。

**给谁用：** 已经从"一个智能体"升级到"并行开三五个 worktree"的独立开发者和小团队（瓶颈不再是模型聪不聪明，而是"我根本不知道哪个会话卡住了、哪个把周额度烧完了"）；用自己订阅跑智能体的重度用户（额度是自己的钱）；需要把智能体工作量算进项目成本的接单团队。

**核心功能：**

1. 舰队收件箱：跨机器、跨 harness 聚合会话状态——运行中 / 等批准 / 已完成待 review / 失败，点开直达对应 worktree 和 diff，不用挨个终端翻。
2. 额度表：按订阅、按项目、按任务三级计量已用与剩余，标出重置时间；某个任务烧得异常快时提前报警，而不是撞到限流才发现。
3. 同题对比：同一 issue 派给 2–3 个智能体时，自动并排展示 diff、测试结果和耗时，一键选一个合并、其余归档，省掉手动开三个终端比对。
4. 手机批准：会话需要人点头时推到手机，批准 / 打回并附一句反馈，离开工位也能让舰队继续转。
5. 周报：每个项目这周智能体跑了多少会话、烧了多少额度、合并了几个 PR——给自己算账，也给客户报账。

**怎么收费：** 免费版单机本地看板（会话收件箱 + 额度表）；$19/月 Pro（多机器聚合、手机批准、同题对比、额度预警）；$49/月团队版（多人共享舰队、按项目成本分摊、周报导出）。成本账：本地读会话文件和订阅用量接口，不转售 token、不碰模型调用，卖的是"别让舰队失控"，不是算力。

**为什么是小团队的机会：** Orca（14 万星）和 t3code（8 万星）都在做"全功能智能体 IDE"，Hub 在 Product Hunt 卖"像跑 5 个一样跑 100 个会话"——大家都在比谁能跑更多。没人认真做"跑多了之后怎么管"：额度谁烧的、哪个在等批准、三个答案选哪个。小团队没有平台工程岗，舰队一失控就只能关终端重开。FleetWatch 只做管理层，天然能挂在任何 harness 上面，不和任何一家抢编辑器。

**诚实边界：** 这是管理层，不是又一个智能体——它不能让单个智能体写得更好，只能让一群智能体不失控。与 11 月 20 日 Neon Review（云端 PR 评审机器人）和 11 月 22 日 LocalLoop（本地单智能体桌面应用）都不同：那两个解决"一个智能体怎么干活"，FleetWatch 解决"十个智能体怎么不打架"。变现未经验证：重度用户是否愿意为"看板 + 预警"付月费存疑，Orca / t3code 若把额度表做进免费版，独立收费空间会被压缩——先用免费本地版测真实会话量（用户到底同时跑几个），再决定收费形态。额度数据能否稳定拿到也取决于各 harness 的用量接口开放程度，第一版必须如实标注哪些数字是估算。

## 为什么是现在

- **GitHub 当日涨星榜被舰队工具占了头尾：** stablyai/orca 当日 +2,328 星居第一（"用你自己的订阅跑一支 bot 舰队"，总星 142,456），pingdotgg/t3code +1,516 星居第五（"一个控制面管你机器上所有编程智能体"，总星 82,179）。同一天两个舰队工具同进前五，说明"并行跑智能体"已经从玩法变成了默认工作方式（涨星数与仓库数据 2026-11-28 00:30 UTC 当场核实）。
- **Product Hunt 周榜第一也是舰队：** Hub——"像跑 5 个一样跑 100 个 Claude Code 或 Codex 会话"——以 422 票居 Week 48 周榜第一（2026-11-28 00:29 UTC 核实）。开发者社区用投票在说同一句话：会话数量上去了，管理跟不上了。
- **Hacker News 首页同日出现会话管理工具：** SessionGraph（把所有编程智能体会话收进一张交互图，本地运行）登上 HN 首页第 23 位，18 分 / 8 评论；Prospero（原生 AI 编程 harness）第 18 位，27 分 / 5 评论（2026-11-28 00:31 UTC 直达 HN 首页核实）。分数还不高，但"会话太多、需要一张图看全"这个痛点已经在首页冒头。
- **额度正在变紧：** HN 首页同日还有"OpenAI 可能进入成本控制模式"等讨论；订阅额度一旦收紧，"哪个任务在烧额度"就从好奇变成算账。舰队越大，盲烧越贵。
- **缺口真实存在：** 跑智能体的工具都在比"能跑多少"，管智能体的默认答案还没出现。窗口期就是现在：舰队工具正在涨星榜上，用户的会话数已经先涨起来了，管理层还空着。
