## 今日 Build Idea：Neon Review——"新科第一的编程模型，给你的 PR 做评审"

**产品：** 接入 Gemini 4 Neon 的 GitHub PR 自动评审机器人。

**给谁用：** 独立开发者和小团队——他们请不起专职 reviewer，Copilot 的 Neon 又只开给 Pro+ / Max / Business / Enterprise 套餐；以及被 PR 淹没的开源维护者。

**核心功能：**

1. 装上 2 分钟：GitHub App 一键安装，新 PR 自动评审，2 分钟内出结论。
2. 结论先行：先给"能合 / 先改这 3 处"，再列细节——不要一堵"nit 墙"。
3. 成本透明：每条评审附 token 花费，让用户自己算账。
4. 越用越懂你的库：从已合并的 PR 里学这个仓库的约定（命名、测试要求、禁止的写法），而不是拿通用规则套所有人。

**怎么收费：** 免费每月 20 个 PR；$12/月不限仓库（个人）；$29/月团队 5 席。成本账（按 Google 官方价 $3 / $15 每百万 token 估算）：一次典型 PR 评审约 5 万输入 + 5 千输出 token，约 $0.23；$12 套餐约 50 个 PR 回本，轻度用户补贴重度用户。

**为什么是小团队的机会：** Copilot 已经有 Neon，但门槛是套餐；大厂评审工具卖的是"合规 + 全套 DevOps"，小团队要的只是一句"这 PR 能不能合 + 哪里会炸"。模型是新的、 verdict 是产品。

**诚实边界：** 模型不是独占——任何人都能调 Gemini API，护城河是 verdict 体验 + 仓库约定学习，不是模型本身；第三方榜单分数不等于你仓库里的实际效果，上线第一周就该拿自己的 PR 做对照评测。

## 为什么是现在

- **2026-11-18，Google 正式发布 Gemini 4 Neon（GA）。** 官方博客称其为"复杂软件工程、知识工作与科学流程"的前沿模型，定价 $3 / $15 每百万 token（输入 / 输出），上下文 1M token。
- **2026-11-19 至 20 日，Neon 冲上 Models Engineering Index 第一（68.4 分）**，超过 OpenAI 6.2 Astra（67.1）和 Anthropic Fable 5.2（66.7）；HN 当日头条 359 分、235 条评论。
- **同日 GitHub Copilot 上架 Neon，等于替模型做了真实性背书**——但只开给 Pro+ / Max / Business / Enterprise，免费与普通 Pro 用户用不上，留下一个"便宜 standalone"的缺口。
- **每次模型换代都是 2–4 周窗口。** 所有把 Claude / GPT 写死成"最好模型"的工具都要重调，晚一步就是跟在别人后面抄参数。
- **1M 上下文让"整库评审"第一次便宜到能卖 $12/月。** 以前逐文件拼上下文的评审机器人，成本和效果都撑不起这个价。
